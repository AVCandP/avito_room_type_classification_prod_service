## 1. Краткое резюме

В проекте реализовано решение для автоматического определения типа помещения по фотографии. Пользователь загружает изображение комнаты, а сервис возвращает предсказанный класс помещения и уверенность модели.

Решение предназначено для автоматизации разметки фотографий в объявлениях недвижимости, контроля качества карточек, улучшения поиска и фильтрации объектов, а также для последующей интеграции в продуктовый пайплайн.

Финальная версия подготовлена как продуктовый сервис:

- модель запускается локально, без отправки изображений во внешние сервисы;
- реализован интерфейс загрузки изображения и получения результата;
- подготовлена контейнеризация через Docker;
- сохранены веса лучшей модели и код инференса;
- подготовлены файлы для публикации проекта в Git;
- оформлены инструкции по запуску и развертыванию.

## 3. Итоговый результат

Лучший результат получен во второй фазе проекта на ансамбле моделей ConvNeXt Base.

| Этап | Подход | Macro F1 |
|---|---|---:|
| Фаза 1 | Базовая модель EfficientNet-B0 | 0.6093 |
| Фаза 2 | Лучшая одиночная модель ConvNeXt Base | 0.7228 |
| Фаза 2 | 3-fold ансамбль ConvNeXt Base, среднее по фолдам | 0.7559 |
| Фаза 2 | Stacking по out-of-fold предсказаниям | 0.7565 |

Финальный submission содержит 48 003 строки с предсказаниями для тестового набора.

По критериям оценки решение соответствует верхнему уровню качества модели: Macro F1 выше 0.60.

## 8. Инструкция по запуску

### Запуск через Docker

Перейти в директорию сервиса:

```powershell
cd <корень>\prectice2curse\avito_room_type_classification_prod_service
```

Собрать и запустить контейнер:

```powershell
docker compose up --build
```

Открыть интерфейс:

```text
http://localhost:7860
```

Остановить сервис:

```powershell
docker compose down
```

### Пересборка контейнера после изменений

```powershell
cd <корень>\prectice2curse\avito_room_type_classification_prod_service
docker compose down
docker compose build --no-cache
docker compose up
```

### Локальный запуск без Docker

```powershell
cd <корень>\prectice2curse\avito_room_type_classification_prod_service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r app\requirements.txt
python app\app.py
```

После запуска открыть:

```text
http://localhost:7860
```

## 9. Подготовка к публикации в Git

В продуктовой директории созданы файлы:

- `.gitignore`;

- `.env.example`;

Так как веса моделей имеют большой размер, для публикации репозитория требуется Git LFS.

Рекомендуемая последовательность:

```powershell
cd <корень>\prectice2curse\avito_room_type_classification_prod_service
git init
git lfs install
git add .gitattributes .gitignore .env.example README.md GIT_PUBLISHING_GUIDE.md
git add app src scripts configs artifacts docs Dockerfile docker-compose.yml
git add models\weights\fold1\best_model.pth models\weights\fold2\best_model.pth models\weights\fold3\best_model.pth
git commit -m "Prepare Avito room classification production service"
```

Перед отправкой в удаленный репозиторий необходимо убедиться, что Git LFS включен на стороне хостинга.

## 11. Ограничения и рекомендации

Ограничения текущей версии:

- скорость инференса на CPU ниже, чем на GPU;
- качество зависит от близости входных фотографий к домену обучающего датасета;
- при публикации репозитория веса моделей необходимо хранить через Git LFS или отдельное model storage;
- для промышленной интеграции рекомендуется добавить REST API и пакетную обработку изображений.

Рекомендации по развитию:

- добавить FastAPI-слой для интеграции с внешними системами;
- добавить endpoint для batch-инференса;
- подключить MLflow или Weights & Biases для истории экспериментов;
- добавить мониторинг качества на новых данных;
- подготовить отдельную страницу с объяснением предсказания через Grad-CAM;
- опубликовать модель и датасетные артефакты в Hugging Face при наличии прав на данные.
